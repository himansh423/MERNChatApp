# <h1>Clyphix - Secure & Private Chatrooms</h1>

<p>Welcome to <strong>Clyphix</strong>, a cutting-edge platform designed to ensure private and secure conversations. Create, manage, and destroy private chatrooms where your chats are end-to-end encrypted and no data is stored in the database.</p>

## <h2>Features</h2>

<ul>
  <li><strong>Create Private Chatrooms:</strong> Set up a private chatroom with a name, password, and participant details.</li>
  <li><strong>Unique Chatroom ID:</strong> Receive a unique ID for each chatroom, making it easy to invite others.</li>
  <li><strong>End-to-End Encryption:</strong> All chats are securely encrypted, ensuring complete privacy.</li>
  <li><strong>No Data Storage:</strong> Chats are not saved on any server, ensuring your conversations remain confidential.</li>
  <li><strong>Self-Destructing Chatrooms:</strong> Destroy the chatroom after your conversation to ensure no traces are left behind.</li>
  <li><strong>Real-Time Messaging:</strong> Chat with others in real time, with support for image sharing.</li>
</ul>

## <h2>Technology Stack</h2>

<ul>
  <li><code>MongoDB</code> - NoSQL Database</li>
  <li><code>Express.js</code> - Web Application Framework</li>
  <li><code>React.js</code> - Frontend Library</li>
  <li><code>Node.js</code> - JavaScript Runtime</li>
  <li><code>WebSockets</code> - Real-Time Communication</li>
  <li><code>Tailwind CSS</code> - Utility-First CSS Framework</li>
  <li><code>GSAP</code> - Animation Library</li>
  <li><code>Nodemailer</code> - Email Verification</li>
  <li><code>JWT</code> - JSON Web Token Authentication</li>
</ul>

## <h2>Getting Started</h2>

<ol>
  <li><strong>Sign Up or Log In:</strong> Begin by signing up or logging in using OTP verification for secure access.</li>
  <li><strong>Create a Chatroom:</strong> Enter a chatroom name, password, and participant details to create your private space.</li>
  <li><strong>Get Your Unique ID:</strong> A unique chatroom ID will be generated. Copy this ID for later use.</li>
  <li><strong>Enter the Chatroom:</strong> Use the "Enter Chatroom" option, paste the copied ID and password, and access your chatroom.</li>
  <li><strong>Invite Others:</strong> Share the ID and password with your chat partner to join the conversation.</li>
  <li><strong>Chat Securely:</strong> Chat in real time, share images, and enjoy full end-to-end encryption.</li>
  <li><strong>Destroy the Chatroom:</strong> Once your conversation is complete, click the delete button to destroy the chatroom.</li>
</ol>

## <h2>Security & Privacy</h2>

<p class="highlight">Your privacy is our priority. Clyphix uses end-to-end encryption for all conversations, ensuring no data is stored on our servers. Once a chatroom is destroyed, all traces of the chat are permanently removed.</p>

## <h2>Installation</h2>

```bash
# Clone the Clyphix repository
git clone https://github.com/your-username/clyphix.git
